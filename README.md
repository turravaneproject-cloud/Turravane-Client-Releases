# Turravane client releases

Official client-only releases for Turravane MU Online Season 9 R1.
The v1.0.4 full client and small patch were published on 20 October 2026.
Downloads: https://github.com/turravaneproject-cloud/Turravane-Client-Releases/releases/tag/v1.0.4.
The official website is https://turravane.com/download.
Use the new client after the coordinated server restart. The operator is
performing the server and VM reboot manually during this release.

v1.0.4 includes a complete client and a small update for complete v1.0.3 installs.
The small patch changes six game files; close MU and back up those files first.
Use the full client for older or incomplete installations. Main.exe and the
accepted connection settings are unchanged. The patch synchronizes teleport
prices and levels, including the special-class level display correction.

Exact archive sizes/hashes and complete per-file manifests are under
releases/v1.0.4. Verify-Client.ps1 is read-only and can check an intact v1.0.3
preimage, the installed patch or a clean full v1.0.4 extraction. Runtime and
server acceptance are separate release gates; never disable integrity controls.

No server source, server configuration/binary, private evidence, credentials,
player data or SQL backup is stored in this client-only repository. Game source
and operational evidence remain in their authorised private repositories.

Old links are removed from the website Downloads section; historical assets are
preserved for recovery. No automatic server or VM reboot is scheduled.
